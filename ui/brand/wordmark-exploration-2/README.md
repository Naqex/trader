# Wordmark exploration — round 2

Twelve owner-requested directions E–P. Open index.html to compare large wordmarks, 128px topbar versions and 24px icons in dark/light. The chooser is a local review aid; runtime assets are unchanged.

E Serif; F Heavy; G Soft; H Orbit; I Badge; J Matrix; K Digital; L Ribbon; M Momentum; N Terminal; O Linked; P Facet.

Font-derived lettering is converted to paths from locally installed Georgia, Impact, Arial Rounded MT Bold, Segoe UI and Consolas. No font files or external resources are bundled. Monograms, matrix and segmented lettering are native SVG geometry. SVG exports inherit currentColor.
