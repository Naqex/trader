# Security

This is pre-1.0 software; no production support window is declared yet.

Do not report credentials, broker account details or private datasets in public
issues. Use GitHub's private vulnerability reporting when enabled. Otherwise
contact a repository maintainer privately before sharing sensitive details.

Rotate a genuinely exposed credential at its issuer. Removing a file or making
a repository private does not revoke a credential or erase existing copies.

PR CI runs on hosted runners with synthetic data. Never attach a personal MT5
terminal, production database or broker credentials to an untrusted PR runner.
