# Live MT5 demo terminal — 22/10/2026

Scope: owner requested broker trading in Live using the practice chart/order UI;
demo first. Implementation and local migration/restart are authorized. Sending
to a broker, configuring an active policy, or launching a terminal was not done.

## Implemented

- Live → Giao dịch MT5 is a lazy page using the existing chart, selects, modal,
  tokens and extracted order fields. Journal routes remain separate.
- Real adapter contract supplies quotes, 300 bars in M1/M5/M15/H1/H4/D1,
  specifications, positions, managed orders and durable request receipts.
- Market placement, managed SL/TP changes, full close, cancel and local pause /
  resume. Dedicated hedging DEMO only; pending placement/partial close unsupported.
- Server policy validates exact workspace/account/server/portable terminal,
  current quote, lots/ticks/stops/freeze, account-wide risk, margin, permissions
  and order_check. Account screenshot is context, never a source of executable
  symbol limits or zero margin/cost assumptions.
- A request ID is persisted before dispatch; uncertain/partial results block
  resends across reload. Reconciliation reads broker evidence without resending.
  Preview expires after five seconds and binds the exact intent.
- Shared modal wm-button styling now also works outside the application DOM.

## Remaining acceptance / resume

- Broker end-to-end, actual terminal attachment, broker comment preservation,
  real margin/fills/fees and latency remain UNVERIFIED. An exact dedicated demo
  terminal/server/symbol/risk scope is needed before activation.
- No real-money mode, pending placement, partial close, auto-login, persistent
  terminal service or multi-client production acceptance is claimed.
- Unknown requests deliberately cannot be cleared from the browser. A transport
  failure before server receipt creation can remain locally pending with 404
  reconciliation. Safe recovery needs a server-side reservation/tombstone design,
